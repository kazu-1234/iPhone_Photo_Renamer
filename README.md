# iPhone Photo Renamer v1.9.4

iPhoneをはじめとするスマートフォンやデジタルカメラで撮影された写真・動画ファイルの日時情報を元に、ファイル名を一括でリネームし、整理するためのWindows用アプリケーションです。Windowsのエクスプローラー上でiPhoneの画像の並びを整理し、見やすくすることを想定しています。

<img src="https://github.com/user-attachments/assets/d87d1875-02b9-4fcb-b45c-5601c6418cd6" alt="メイン画面" width="500" />

## 主な機能

1.  **日時リネーム**: EXIF情報（なければ作成日時）を元に、ファイル名を時系列順に変更します。
    *   例: `IMG_0001.JPG`, `IMG_0002.MOV` ...
2.  **HEIC変換**: iPhoneの写真形式 `.HEIC` を一般的な `.jpg` に自動変換できます。
3.  **編集後データの優先**: iPhoneで編集した写真（`IMG_E...`）を検出し、元画像と比較して優先的に保存します。
4.  **不要ファイル掃除**: `.AAE` ファイル（編集メタデータ）を自動的に削除（ゴミ箱へ移動）できます。
5.  **GUI操作**: ドラッグ＆ドロップやフォルダ選択で簡単に操作できます。
6.  **自動アップデート確認**: GitHubのリリースページから最新バージョンを確認できます。

## 使い方

1.  `iPhone_Photo_Renamer.exe` を起動します。
2.  「フォルダを選択」または「ファイルを選択」から、整理したいファイルが含まれる場所を選びます。
3.  リネーム設定（接頭辞、桁数、開始番号）を確認します。
4.  変換オプション（HEIC変換など）を選択します。
5.  「名前を変更して新しいフォルダにコピー」をクリックします。
6.  保存先フォルダを選択すると処理が始まります。

## インストール

特別なインストールは不要です。配布された `.exe` ファイルを実行するだけで使用できます。

### 開発環境での実行
Python環境で実行する場合は以下のライブラリが必要です:

```bash
pip install Pillow pillow-heif send2trash
```

- `Pillow`: 画像処理、EXIF取得
- `pillow-heif`: HEIC画像の読み込み
- `send2trash`: ファイルをゴミ箱に送る機能
